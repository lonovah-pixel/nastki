# STALKER RP — сборка сервера Garry's Mod (DarkRP)

Готовая сборка ролевого сервера по мотивам S.T.A.L.K.E.R. на DarkRP: КПК, инвентарь, группировки
с захватом территорий и казной, торговцы и квестодатели, аномалии и артефакты, мутанты и разделка туш,
крафт и готовка, события Зоны, выбросы и радиация, знакомства и нашивки, админ-панель «Комендант»,
связанная с ULX, и русская локализация DarkRP.

Сборка не требует стороннего контента: модели, звуки и эффекты — из базового Garry's Mod и
Half-Life 2. Нужен только игровой режим DarkRP.

## Состав

| Папка | Назначение |
|---|---|
| `stalker_core` | Общее ядро: тема оформления, реестр настроек для админ-панели, метки на карте и экране, лента новостей, статистика, действие «удерживайте E», вкладки КПК |
| `stalker_pda` | КПК (F4): сводка, карта с метками, новости, статистика, энциклопедия Зоны, личные сообщения, справочник, вкладки модулей |
| `stalker_inventory` | Инвентарь (TAB): 40 ячеек, экипировка, быстрые слоты, характеристики и износ брони, компактные тайники и наводки на чужие тайники |
| `stalker_zone` | Аномалии, артефакты и детекторы, логова мутантов, каталог снаряжения, защиты костюмов, голод и жажда, рюкзак погибшего, ассортимент торговцев, памятка новичка |
| `stalker_factions` | 11 группировок: вступление у вербовщика или по приглашению, звания, казна и доход точек, захват по флагу, способности командования, дипломатия и войны (F6) |
| `stalker_quests` | Квестодатели, случайные задания, трекер и направляющая линия к цели (GUIDE LINE), «Путь новичка» |
| `stalker_events` | События Зоны (сбитый груз, гон мутантов, артефактный шторм, военный рейд, охота за головой), маячки игроков, точки интереса |
| `stalker_crafting` | Крафт из деталей и трофеев, верстаки, костры и готовка |
| `stalker_social` | Знакомства («Незнакомец»), меню взаимодействия (G), нашивки, жесты и позы (H) |
| `stalker_npc_dialog_trade` | NPC-торговцы с диалогами, сделки через кошелёк DarkRP |
| `stalker_butchering` | Разделка туш мутантов мини-игрой, трофеи |
| `stalker_emissions` | Выбросы по расписанию: укрытия, обморок, урон |
| `stalker_survival` | Радиация (доза, фон, зоны с редактором) и безопасный полный вайп с резервной копией |
| `stalker_remote_admin` | «Комендант» (F7): уровни = группы ULX, права `stalker_*` в XGUI, баны ULib, все настройки сборки, вкладки подсистем |
| `darkrpmodification` | DarkRP под Зону: профессии, валюта ₽, без F4-меню DarkRP, HUD в теме КПК, русский язык |
| `ulib`, `ulx` | ULib 2.71 / ULX 3.81 — группы, права, баны |
| `server/cfg/server.cfg` | Пример конфигурации сервера |
| `tools/` | Сборка архива релиза, генераторы иконок, тесты в эмуляции GMod |

Подробности по каждому аддону — в его `README.md`.

## Требования

* Выделенный сервер Garry's Mod (SRCDS) под Windows или Linux.
* Игровой режим **DarkRP** — [Мастерская Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=248302805) или [GitHub](https://github.com/FPtje/DarkRP) (папка `garrysmod/gamemodes/darkrp`). Скрипт сборки может скачать его сам.
* База данных — встроенный SQLite (`garrysmod/sv.db`), MySQL не нужен.

## Установка

1. Соберите архив релиза (или скачайте готовый):
   ```bash
   python3 tools/build_release.py              # dist/stalker-rp-<версия>.zip
   python3 tools/build_release.py --with-darkrp  # + gamemodes/darkrp с GitHub
   ```
   В архиве папка `garrysmod/` с `addons/`, `cfg/server.cfg` и (по флагу) `gamemodes/darkrp`.
2. Распакуйте архив поверх папки сервера, чтобы получилось `garrysmod/addons/stalker_core/...`,
   `garrysmod/addons/darkrpmodification/...` и т. д. Без архива можно скопировать папки аддонов из
   репозитория в `garrysmod/addons/` вручную.
3. Отредактируйте `garrysmod/cfg/server.cfg`: название, пароль RCON, FastDL при необходимости.
4. Запустите сервер с режимом DarkRP:
   ```bash
   ./srcds_run -game garrysmod -console -port 27015 +maxplayers 32 +gamemode darkrp +map gm_construct
   ```
   Для атмосферы подключите STALKER-карту из Мастерской через `+host_workshop_collection <ID коллекции>`
   и укажите её в `+map`.
5. Назначьте себя владельцем в **консоли сервера** — команда сама добавит вас в группу ULX `superadmin`:
   ```text
   sta_setrole 7656119XXXXXXXXXX owner
   ```

Игрокам материалы (иконки, эмблемы, нашивки) отправляются через `resource.AddFile`: оставьте
`sv_allowdownload 1` или настройте FastDL (`sv_downloadurl`) для быстрой загрузки.

ULX после первого запуска создаёт `garrysmod/data/ulx/config.txt`: там меняются приветствие
(`ulx welcomemessage`) и MOTD (`ulx showMotd 0` — выключить, новичкам и так открываются памятка и «Путь новичка»).

## Первый запуск: подготовка карты

Все размещения сохраняются отдельно для каждой карты. Почти всё делается из «Коменданта» (F7).

| Шаг | Как | Где хранится |
|---|---|---|
| Торговцы | F6 → «Админ-панель →» → торговцы: «Поставить торговца под прицел», «Сохранить расстановку». Либо `stnpc_spawn sidor` + `stnpc_save` | `data/stalker_npc/<карта>.json` |
| Вербовщики | F6 → «Админ-панель →» → «Поставить вербовщика» | SQLite `stfw_world` |
| Территории, базы и флаги | F6 → «Админ-панель →» → «+ Новая точка» (база = место возрождения группировки). Флаг захвата ставится на точке сам | SQLite `stfw_world` |
| Поля аномалий и логова мутантов | F7 → «Зона» → «Открыть редактор Зоны» или `!zone` | `data/stalker_zone/<карта>.json` |
| Радиационные зоны | F7 → «Радиация» или `stalker_rad_menu`: создать под прицелом, имя, радиус, доза, спад | `data/stalker_radiation/<карта>.json` |
| Квестодатели и места заданий | F7 → «Задания» или `stq_menu` (`!questadmin`) | `data/stalker_quests/<карта>.json` |
| Места событий и точки интереса | F7 → «События» или `stev_menu` (`!events`) | `data/stalker_events/<карта>.json` |
| Верстаки и постоянные костры | F7 → «Крафт» или `stcraft_admin` (`!craftadmin`) | `data/stalker_craft/<карта>.json` |
| Точки возрождения профессий | DarkRP: `/setspawn stalker`, `/setspawn duty` и т. д. | SQLite DarkRP |
| Все числа баланса | F7 → «Настройки» (поиск, разделы по аддонам, сброс к умолчанию) | SQLite `stalker_settings` |

Профили торговцев: `sidor` (одиночки), `trader_duty`, `trader_freedom`, `trader_bandits`, `trader_mercs`,
`trader_monolith`, `trader_military`, `trader_clearsky`, `trader_scientists`, `trader_ecologists`, `trader_renegades`.

## Игровой цикл

1. Новичок появляется «Сталкером» с 3000 ₽ и стартовым набором. Его ведёт «Путь новичка»: метка и линия
   на земле показывают, куда идти — к торговцу, за детектором, к полю аномалий, к Бармену, в КПК, к вербовщику.
2. Сталкер берёт задания у квестодателей, ищет артефакты, охотится на мутантов и разделывает туши,
   крафтит из деталей и готовит еду у костра.
3. Продаёт хабар торговцам: цены зависят от состояния, репутации и отношений группировок.
4. Знакомится с другими игроками (G — «Представиться»): до этого все видят друг друга как «Незнакомец».
5. Вступает в группировку у вербовщика (взнос) или по приглашению лидера. Профессия группировки выдаётся сама.
6. Группировки захватывают точки (удержание E на флаге), получают доход в казну, лидер управляет составом,
   званиями и способностями.
7. События Зоны (грузы, гон, шторм, рейды, охота за головой) и выбросы меняют обстановку; после выброса
   Зона перестраивается.
8. Смерть стоит содержимого рюкзака: сумка остаётся на месте гибели, а с убитого может выпасть наводка на его тайник.

## Профессии

| Категория | Профессии |
|---|---|
| Вольные сталкеры | Сталкер (по умолчанию) |
| Группировки | Боец «Долга», Боец «Свободы», Бандит, Наёмник, Монолитовец, Военный, Боец «Чистого Неба», Ренегат |
| Наука и экология | Учёный, Эколог |
| Служебное | Администрация (только для админов) |

Меню F4 DarkRP отключено: на F4 открывается КПК. Профессию нельзя сменить вручную — её выдаёт вступление
в группировку (у вербовщика или по приглашению лидера), а исключение возвращает в «Сталкера».
Профессии не выдают оружие и броню — всё берётся из инвентаря.

## Администрирование

### «Комендант» и ULX

* Уровни «Коменданта» — это группы ULX: назначение уровня в панели или `sta_setrole <SteamID64> <уровень>`
  меняет группу ULX (работает и для игроков не в сети).
* Права сборки — CAMI-привилегии `stalker_<право>` (zone, radiation, events, quests, craft, factions, settings и др.):
  их можно раздавать группам в XGUI (`xgui`, вкладка «Groups»).
* Баны и кики идут через ULib; журнал действий дублируется в журнал ULX.
* Команды в меню ULX (категория STALKER): `ulx stalkeritem`, `ulx stalkerdose`, `ulx stalkerfaction`,
  `ulx emissionstart`/`emissionstop`, `ulx zonerebuild`, `ulx stalkerrestock`, `ulx stalkerevent`/`stalkerstopevent`.

### Вкладка «Настройки»

Все числовые и логические параметры аддонов собраны в «Коменданте» → «Настройки»: поиск, разделы
(«Аномалии», «Артефакты», «Мутанты», «Выживание», «Радиация», «Выбросы», «Группировки», «Инвентарь»,
«События», «Задания», «Крафт и готовка», «КПК», «Знакомства и нашивки», «Торговля», «Разделка туш»,
«Комендант» и др.), подсветка изменённых, сброс к умолчанию. Изменения применяются сразу и сохраняются
в SQLite `stalker_settings`. Из консоли: `stalker_setting [id] [значение|default]`.

## Данные и вайп

Прогресс игроков (инвентари, тайники и наводки, группировки, казна, задания, знакомства, нашивки,
сообщения КПК, статистика, склады торговцев, разделка, патроны) хранится в `garrysmod/sv.db`, разметка карт —
в `garrysmod/data/`. Делайте копию `sv.db` и `data/` перед обновлениями.

Полный вайп: `stalker_fullwipe` в консоли — сервер сначала сохранит резервную копию в `data/stalker_wipe/backup_*`,
затем при следующем запуске очистит прогресс игроков и разметку карт (Зона, радиация, события, задания, крафт,
торговцы, выбросы). Настройки «Коменданта» (`stalker_settings`), уровни и баны администрации не стираются.

## Проверка и выпуск

```bash
tools/test/run.sh              # синтаксис + сценарии в эмуляции GMod (нужны luajit и libsqlite3)
python3 tools/build_release.py  # архив релиза в dist/
python3 tools/gen_icons.py      # пересобрать иконки предметов Зоны (есть и gen_icons_*.py других аддонов)
```

Тесты загружают все аддоны в серверном и клиентском окружении эмуляции GMod и прогоняют сценарии каждого
аддона: вступление и захват точек, казну, админ-панель с моком ULX, радиационные зоны, тайники и наводки,
события, КПК и сообщения, знакомства и позы, задания и обучение, крафт и готовку, Зону и DarkRP.
Это эмуляция: перед открытием сервера пройдите таблицу «Первый запуск» на живом сервере и проверьте
внешний вид окон, анимаций и эффектов в игре.

## Известные ограничения

* Ассетов S.T.A.L.K.E.R. нет: мутанты — NPC Half-Life 2, модели игроков и квестодателей — стандартные модели GMod/HL2.
* Скрытие имён косметическое: настоящий ник виден в табло Steam и консоли.
* Подложки карт для КПК в сборку не входят: без них вкладка «Карта» показывает схему с сеткой по меткам
  (материал и границы задаются в `stalker_pda/lua/stalker_pda/sh_config.lua`).
* Запас патронов теряется при смерти (сохраняется только при выходе с сервера); содержимое сумок погибших,
  грузов событий и маячки не переживают рестарт карты.
