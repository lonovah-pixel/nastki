# STALKER RP — сборка сервера Garry's Mod (DarkRP)

Готовая сборка ролевого сервера по мотивам S.T.A.L.K.E.R. на DarkRP: инвентарь в стиле КПК,
группировки с войнами за территории, торговцы, аномалии и артефакты, мутанты и разделка туш,
выбросы, радиация, админ-панель и русская локализация DarkRP.

Сборка не требует стороннего контента: модели, звуки и эффекты — из базового Garry's Mod и
Half-Life 2. Нужен только игровой режим DarkRP.

## Состав

| Папка | Назначение |
|---|---|
| `darkrpmodification` | Настройка DarkRP под Зону: профессии и категории F4, валюта ₽, отключённые полиция/мэр/принтеры/лотерея, HUD-плашка КПК, русский язык DarkRP |
| `ulib`, `ulx` | ULib 2.71 / ULX 3.81 — группы, права, баны (стандартные, без изменений) |
| `stalker_inventory` | Инвентарь-КПК (TAB): 40 ячеек, экипировка, быстрые слоты, личные тайники, сохранение в SQLite |
| `stalker_npc_dialog_trade` | NPC-торговцы с диалогами, сделки через кошелёк DarkRP |
| `stalker_factions` | 11 группировок (+ мутанты и зомби), вербовщики, лидеры, дипломатия, войны, захват территорий, базы, радар (F6) |
| `stalker_butchering` | Разделка туш мутантов мини-игрой, трофеи на продажу |
| `stalker_emissions` | Выбросы по расписанию: укрытия, обморок, урон |
| `stalker_survival` | Радиация (доза, фон, зоны) и безопасный полный вайп с резервной копией |
| `stalker_remote_admin` | Панель «Комендант» (F7): дисциплина, телепорт, выдача, баны, журнал |
| `stalker_zone` | **Новый аддон**: аномалии, артефакты и детекторы, логова мутантов, каталог снаряжения, защиты костюмов, голод/жажда, рюкзак погибшего, ассортимент и восполнение торговцев, памятка новичка |
| `server/cfg/server.cfg` | Пример конфигурации сервера |
| `tools/` | Сборка архива релиза, генератор иконок, smoke-тесты |

Подробности по каждому аддону — в его `README.md`.

## Требования

* Выделенный сервер Garry's Mod (SRCDS) под Windows или Linux.
* Игровой режим **DarkRP** — [Мастерская Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=248302805) или [GitHub](https://github.com/FPtje/DarkRP) (папка `garrysmod/gamemodes/darkrp`). Скрипт сборки может скачать его сам.
* База данных — встроенный SQLite (`garrysmod/sv.db`), MySQL не нужен.

## Установка

1. Соберите архив релиза (или скачайте готовый):
   ```bash
   python3 tools/build_release.py              # dist/stalker-rp-<версия>.zip
   python3 tools/build_release.py --with-darkrp  # + gamemodes/darkrp с GitHub
   ```
   В архиве папка `garrysmod/` с `addons/`, `cfg/server.cfg` и (по флагу) `gamemodes/darkrp`.
2. Распакуйте архив поверх папки сервера, чтобы получилось `garrysmod/addons/stalker_inventory/...`,
   `garrysmod/addons/darkrpmodification/...` и т. д. Без архива можно скопировать папки аддонов из
   репозитория в `garrysmod/addons/` вручную.
3. Отредактируйте `garrysmod/cfg/server.cfg`: название, пароль RCON, FastDL при необходимости.
4. Запустите сервер с режимом DarkRP:
   ```bash
   ./srcds_run -game garrysmod -console -port 27015 +maxplayers 32 +gamemode darkrp +map gm_construct
   ```
   Для атмосферы подключите STALKER-карту из Мастерской через `+host_workshop_collection <ID коллекции>`
   и укажите её в `+map`.
5. Выдайте себе права в **консоли сервера**:
   ```text
   ulx adduserid STEAM_0:1:12345678 superadmin
   sta_setrole 7656119XXXXXXXXXX owner
   ```

Игрокам материалы (иконки, панели КПК) отправляются через `resource.AddFile`: оставьте
`sv_allowdownload 1` или настройте FastDL (`sv_downloadurl`) для быстрой загрузки.

ULX после первого запуска создаёт `garrysmod/data/ulx/config.txt`: там меняются приветствие
(`ulx welcomemessage`) и MOTD (`ulx showMotd 0` — выключить, новичкам и так открывается «Памятка сталкера»).

## Первый запуск: подготовка карты

Все размещения сохраняются отдельно для каждой карты в `garrysmod/data/`.

| Шаг | Как | Где хранится |
|---|---|---|
| Торговцы группировок | F6 → «Админ-панель →» → торговцы: «Поставить торговца под прицел», затем «Сохранить расстановку». Либо `stnpc_spawn sidor` + `stnpc_save` | `data/stalker_npc/<карта>.json` |
| Вербовщики | F6 → «Админ-панель →» → «Поставить вербовщика» | SQLite `stfw_world` |
| Территории и базы | F6 → «Админ-панель →» → «+ Новая точка» (база = место возрождения группировки) | SQLite `stfw_world` |
| Поля аномалий и логова мутантов | `!zone` (редактор Зоны) | `data/stalker_zone/<карта>.json` |
| Радиационные зоны | Кнопка в редакторе Зоны или `stalker_rad_add <радиус> <доза/с>` | `data/stalker_radiation/<карта>.json` |
| Расписание выбросов | `stem_menu` | `data/stalker_emissions/settings.json` |
| Точки возрождения профессий | DarkRP: `/setspawn stalker`, `/setspawn duty` и т. д. | SQLite DarkRP |

Профили торговцев: `sidor` (одиночки), `trader_duty`, `trader_freedom`, `trader_bandits`, `trader_mercs`,
`trader_monolith`, `trader_military`, `trader_clearsky`, `trader_scientists`, `trader_ecologists`, `trader_renegades`.

## Игровой цикл

1. Новичок появляется «Сталкером» с 3000 ₽ и стартовым набором, видит «Памятку сталкера».
2. Покупает детектор, ищет артефакты у аномалий, охотится на мутантов и разделывает туши.
3. Продаёт хабар торговцам: цены зависят от состояния, репутации и отношений группировок.
4. Вступает в группировку у вербовщика (взнос или допуск лидера) — в F4 открывается её профессия.
5. Группировки воюют за территории, копят очки снабжения и покупают улучшения.
6. Выброс загоняет всех в укрытия, после него Зона перестраивается и появляются новые артефакты.
7. Смерть стоит содержимого рюкзака: сумка остаётся на месте гибели на 10 минут.

## Управление

| Клавиша / команда | Действие |
|---|---|
| TAB | Инвентарь-КПК (рюкзак, экипировка, артефакты, карта, PDA со списком «в сети») |
| ALT + 1–9 | Быстрые слоты |
| E | Торговцы, вербовщики, подбор предметов и артефактов, разделка, сумки погибших |
| F4 | Профессии DarkRP |
| F6 | Сеть группировок: территории, дипломатия, ранг; меню лидера и админа |
| F7 | «Комендант» (для персонала) |
| F1 | Справка DarkRP и чат-команды |
| `!help` | Памятка сталкера |
| `!stash` | Личные тайники |
| `stb_claim` | Забрать добычу разделки, не влезшую в рюкзак |

## Профессии (F4)

| Категория | Профессии |
|---|---|
| Вольные сталкеры | Сталкер (по умолчанию), Полевой медик, Проводник |
| Группировки | Боец «Долга», Боец «Свободы», Бандит, Наёмник, Монолитовец, Военный, Боец «Чистого Неба», Ренегат |
| Наука и экология | Учёный, Эколог |
| Служебное | Администрация (только для админов) |

Профессия группировки доступна только её члену; вступление у вербовщика сразу переводит в неё,
исключённый игрок возвращается в «Сталкера». Профессии не выдают оружие и броню — всё берётся из инвентаря (у медика только аптечка DarkRP).

| `!setfaction <SteamID64> <id>`, `!rep`, `!war`, `!capture` | Быстрые команды группировок |
| `stnpc_spawn <профиль>`, `stnpc_save` | Поставить и сохранить торговцев |
| `stem_menu`, `stem_start`, `stem_stop` | Выбросы |
| `stalker_rad_add`, `stalker_rad_list`, `stalker_rad_remove` | Радиационные зоны |

## Данные и вайп

Прогресс игроков (инвентари, тайники, группировки, склады торговцев, журнал сделок, разделка,
патроны) хранится в `garrysmod/sv.db`. Делайте копию `sv.db` и папки `garrysmod/data/` перед
обновлениями. Полный вайп: `stalker_fullwipe` в консоли — сервер сначала сохранит резервную копию
в `data/stalker_wipe/backup_*`, затем очистит данные при следующем запуске.

## Проверка и выпуск

```bash
tools/test/run.sh              # синтаксис + smoke-тесты в эмуляции GMod (нужны luajit и libsqlite3)
python3 tools/build_release.py  # архив релиза в dist/
python3 tools/gen_icons.py      # пересобрать иконки предметов STALKER Zone
```

Smoke-тесты загружают все аддоны в серверном и клиентском окружении и прогоняют сценарии:
стартовый набор, склады и восполнение торговцев, редактор Зоны, подбор артефакта детектором,
урон аномалий, защиты костюмов и шлемов, голод, рюкзак погибшего, патроны при переподключении,
логова мутантов, перестройку Зоны после выброса, конфигурацию DarkRP и русскую локализацию.
Это эмуляция: перед открытием сервера пройдите таблицу «Первый запуск» на живом сервере.

## Известные ограничения

* Ассетов S.T.A.L.K.E.R. нет: мутанты — NPC Half-Life 2, модели игроков — стандартные модели GMod.
  Модели профессий меняются в `jobs.lua`, модели артефактов — в `sh_items.lua`.
* TAB занят инвентарём; таблица игроков заменена списком «в сети» во вкладке PDA.
  Вернуть стандартный TAB: `stalker_inv_key 0` и `bind i stalker_inv`.
* Запас патронов теряется при смерти (сохраняется только при выходе с сервера).
* Содержимое сумок погибших не переживает рестарт карты.
