# STALKER PDA

КПК сталкера — единое окно сборки на клавише **F4** (меню F4 DarkRP перехватывается). Работает поверх
STALKER Core (тема, сеть, метки, новости, статистика, реестр вкладок); данные инвентаря, радиации, выбросов,
Зоны, группировок, заданий и знакомств читает, только если эти аддоны установлены, и не падает без них.

## Как открыть

| Способ | Что делает |
|---|---|
| F4 (бинд `gm_showspare2`) | открыть / закрыть КПК; в открытом окне F4 закрывает его |
| `!кпк`, `!pda`, `/кпк`, `/pda` в чате | открыть КПК |
| `stalker_pda [вкладка]` в консоли | открыть / закрыть; с аргументом — сразу на вкладке |
| `STALKER_CORE.OpenPDA(tab)` | для других аддонов (кнопка «Открыть КПК» в инвентаре) |

Без сознания (после выброса) КПК не открывается и закрывается.

## Вкладки

Окно 1120×720, вертикальные вкладки слева. Сначала свои, затем вкладки модулей из `STALKER_CORE.RegisterPDATab`
(«Группировка», «События», «Тайники» и т. д.) под заголовком «МОДУЛИ». Значок у вкладки — `badge()`.

| ID | Вкладка | Содержимое |
|---|---|---|
| `summary` | Сводка | имя, группировка и звание, профессия, счёт; здоровье и броня; доза и фон радиации; сытость и вода (`STALKER_INV.Inventory`); выброс и прогноз (`ST_EMISSION.State`); активные задания (`STALKER_QUESTS.ActiveSummary`); непрочитанные сообщения; 5 последних новостей |
| `map` | Карта | подложка карты или схема с сеткой; метки `STALKER_MARKERS.All()` (кроме `map=false`) с цветами и подписями; фильтр по типам; колесо — масштаб, перетаскивание — сдвиг; подсказка при наведении; ЛКМ — своя метка (стрелка у края экрана, снимается сама у цели), ПКМ — убрать |
| `news` | Новости | лента `STALKER_CORE.NewsFeed` с фильтром по видам |
| `stats` | Статистика | свои счётчики и топ-10 по выбранному ключу (`STALKER_CORE.RequestStats`) |
| `encyclopedia` | Энциклопедия | аномалии, артефакты и детекторы (свойства, цены), мутанты (награда, разделка), группировки (отношения, взнос), выбросы (фазы), радиация (порог, лечение, защита) — цифры из конфигов сервера; поиск |
| `messages` | Сообщения | личная переписка (см. ниже) |
| `guide` | Справочник | управление, как выжить, как заработать, КПК, группировки, задания, тайники, крафт, готовка, события, правила; поиск |

### Подложка карты

Картинка — вид сверху, север (+Y) вверху. Задаётся для каждой карты материалом и границами мира, которые она
охватывает: `STALKER_PDA.Config.MapMaterials/MapBounds` (в `lua/stalker_pda/sh_config.lua`) или
`STALKER_INV.Config.MapMaterials/MapBounds` (общая с инвентарём). Границы: `{x1=,y1=,x2=,y2=}`,
`{minx,miny,maxx,maxy}` или `{mins=Vector,maxs=Vector}`. Без подложки рисуется схема с сеткой по меткам и игроку.

## Личные сообщения

* Адресат — игрок в сети или тот, с кем уже была переписка (в том числе не в сети): сообщение ждёт его входа,
  при входе приходит уведомление с числом непрочитанных.
* Хранение — SQLite `stalker_pda_messages`; старше `pda.message_days` дней удаляются раз в час. Переписку можно
  удалить у себя; строки, удалённые обеими сторонами, стираются из базы.
* Сервер проверяет длину (символы UTF-8), паузу между отправками, лимит непрочитанных от одного отправителя,
  мут ULX (`ulx mute`), сознание отправителя и частоту запросов. Клиент показывает счётчик символов, паузу и ошибки.
* Имена — через `STALKER_SOCIAL.DisplayName`, если модуль знакомств установлен; после выхода собеседника КПК
  показывает то имя, под которым его видел игрок, а не настоящий ник.
* Новое сообщение — всплывающее уведомление и значок на вкладке «Сообщения».

## API

Клиент:
* `STALKER_PDA.Open(tab)`, `Close()`, `Toggle(tab)`, `IsOpen()`, `Select(tab)`.
* `STALKER_PDA.OpenMessages(sid)` — открыть переписку с игроком (SteamID64).
* `STALKER_PDA.AddGuide(id, {title, subtitle, group, order, blocks})` — раздел справочника; `blocks` — список
  (`"абзац"`, `{head="…"}`, `{"Ключ","Значение",токен}`, `{note="…"}`) или функция, которая его возвращает.
* Хуки: `STALKER_PDA_Opened(frame)`, `STALKER_PDA_Closed()`, `STALKER_PDA_TabSelected(id, panel)`,
  `STALKER_PDA_NewMessage(msg, name)`, `STALKER_PDA_Waypoint(pos|nil)`.

Сервер:
* `STALKER_PDA.SendMessage(ply, sid, text)` → `true, msg` или `false, "причина"`.
* `STALKER_PDA.SystemMessage(ply|sid, text, {key="sidor", name="Сидорович"})` — служебное сообщение от NPC или
  системы (ответить нельзя), доходит и до игрока не в сети.
* `STALKER_PDA.UnreadCount(sid)`, `Inbox(ply)`, `Thread(ply, sid)`.
* Хуки: `STALKER_PDA_CanMessage(ply, sid, text)` (false — запретить), `STALKER_PDA_Message(ply, sid, text, target)`.

## Настройки

«Комендант» → «Настройки» → «КПК» (или `stalker_setting pda.<id> <значение>`): `message_length` (длина
сообщения), `message_days` (хранение, дней), `message_interval` (пауза между сообщениями, с), `unread_limit`,
`history_limit`, `message_toast`, `f4`, `emission_forecast`, `waypoint_reach`, `rules_link`.
