# STALKER Remote Admin — «Комендант»

Панель администрирования в стиле КПК для сборки STALKER RP. Работает рядом с ULX: уровни
доступа берутся из групп ULX (`superadmin`, `admin`, `moderator`, `operator`) или назначаются
вручную в самой панели.

## Открытие

* `F7`, `!admin` в чате или `sta_menu` в консоли (клавиша меняется переменной `sta_key`).
* Выберите цели слева, затем раздел и команду. ПКМ по игроку — сведения о нём.

## Первый владелец

Владелец назначается только из **серверной** консоли:

```text
sta_setrole 7656119XXXXXXXXXX owner
```

Либо пропишите SteamID64 в `lua/stalker_admin/sh_config.lua` → `Owners`.

## Уровни доступа

| Уровень | Ранг | Права |
|---|---|---|
| Сталкер | 0 | нет |
| Наблюдатель (`operator`) | 10 | наблюдение, предупреждения, телепорт, журнал |
| Модератор (`moderator`) | 30 | + кик, бан до 1 дня, мут, заморозка, реестр банов |
| Администратор (`admin`) | 60 | + бан до 7 дней, состояние игроков, полёт, снаряжение, объявления, Зона |
| Комендант (`superadmin`) | 90 | всё |
| Владелец | 100 | всё, назначение уровней |

Нельзя действовать на цель с равным или более высоким уровнем. Все действия пишутся в журнал
(`sta_audit`, хранится 90 дней).

## Разделы

* **Дисциплина** — предупреждение, кик, бан, мут чата/голоса, заморозка.
* **Состояние** — лечение, броня, возрождение, бессмертие.
* **Перемещение** — наблюдение через камеру игрока, полёт, телепорт к себе/к игроку/обратно.
* **Снаряжение** — оружие из белого списка, предметы STALKER Inventory, деньги DarkRP.
* **Зона** — группировка игрока, доза радиации, запуск и остановка выброса.
* **Сервер** — объявление, очистка карты, смена и перезапуск карты.
* **Реестр банов / Допуски** — офлайн-бан по SteamID64, разбан, назначение уровней.

Белый список оружия и список карт — в `lua/stalker_admin/sh_config.lua`.
Баны «Коменданта» хранятся отдельно от банов ULX (таблица `sta_bans`).
